## Instrumentos previstos

- Ficha del corpus: fuente, periodo, criterios de selección, cantidad, soporte por clase y condiciones de acceso.
- Guía de anotación: categorías, criterios de asignación y resolución de ambigüedades.
- Manifiesto de partición: identificador de comentario, subconjunto y agrupación para controlar duplicados o publicaciones relacionadas.
- Ficha de ejecución: modelo, versión, parámetros, semillas, preprocesamiento y recursos.
- Archivo de predicciones: identificador, etiqueta de referencia, predicción y ejecución.
- Script de evaluación: métricas por clase, agregados y matriz de confusión.

Se describen los instrumentos que deberán construirse; no se afirma que existan datos o resultados experimentales.
