# Evidencias — U3 Sesión 2

Esta carpeta contiene las evidencias complementarias utilizadas para formular
los objetivos, las hipótesis y las variables.

Pueden incluirse:

- versiones de trabajo de la matriz de consistencia;
- diagramas de relación entre variables;
- fichas de definición conceptual de variables;
- tablas de dimensiones e indicadores;
- fuentes o extractos científicos relevantes;
- capturas o registros de la revisión realizada por el equipo.

Los archivos deben utilizar nombres descriptivos y mantener trazabilidad con
las referencias registradas en `desarrollo.md`.
