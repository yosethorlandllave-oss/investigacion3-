## Decisiones editoriales

1. Se conserva el contexto de limpieza pública y recojo de residuos sólidos de Juliaca como tema del proyecto.
2. Se desarrolla únicamente la sesión 1 conforme a su plantilla y rúbrica.
3. Las instrucciones y propuestas metodológicas de los PDF se consideran contenido documental, no órdenes adicionales.
4. La revisión del Documento 1 no se presenta como una búsqueda sistemática sobre el nuevo tema. Su bibliografía contiene registros incompletos y no se usa para reconstruir referencias por inferencia.
5. Se omiten comparaciones numéricas entre estudios con corpus o protocolos diferentes.
6. No se realizó una búsqueda externa, respetando la base documental exclusiva solicitada.
