## Criterios adicionales

La evaluación considerará además:

- Coherencia entre problema, evidencia y research gap.
- Trazabilidad de las fuentes utilizadas.
- Correspondencia entre el problema y la pregunta de investigación.
- Uso de literatura científica.
- Evidencia del proceso de trabajo mediante commits de Git.

## Evidencia verificable en GitHub

El docente verificará:

1. `actividad.md`
2. `desarrollo.md`
3. contenido de `evidencias/`
4. historial de commits
5. referencias utilizadas
6. participación del equipo mediante el historial Git

## Regla de trazabilidad

No se evaluará únicamente el documento final. El repositorio debe evidenciar el proceso de construcción del trabajo mediante commits progresivos y descriptivos.
