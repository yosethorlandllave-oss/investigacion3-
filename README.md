# Perfil de Proyecto de Investigación — Investigación III

Escuela Profesional de Ingeniería de Sistemas  
Universidad Peruana Unión

## Propósito

Este repositorio permite desarrollar, versionar y documentar el Perfil de Proyecto de Investigación (PPI) durante las unidades 3 y 4 del curso Investigación III.

## Organización

- `sesiones/` — actividades y evidencias de cada sesión.
- `ppi/` — componentes que conforman el Perfil de Proyecto de Investigación.
- `literatura/` — documentación relacionada con la revisión de literatura.
- `instrumentos/` — instrumentos de recolección de datos.
- `experimentos/` — scripts, datos y resultados experimentales.
- `figuras/` — figuras utilizadas en el proyecto.
- `anexos/` — material complementario.
- `feedback/` — observaciones y retroalimentación.
- `rubricas/` — criterios de evaluación.
- `entregables/` — documentos generados.
- `scripts/` — automatización de la construcción del PPI.
- `template/` — recursos para generar el documento final.

## Datos del proyecto

Los estudiantes deben editar el archivo:

`proyecto.yaml`

para registrar el título del proyecto y los integrantes.

## Regla de trabajo

Cada avance significativo debe registrarse mediante Git.

Ejemplo:

git add .
git commit -m "sesion 1: identifica problema y justificacion"
git push

El historial de Git constituye evidencia del proceso de elaboración del PPI.
